# 2026-08-23 TIS
## 타이틀: [Special Permutations](https://leetcode.com/problems/special-permutations/description/)
> 풀이 시간: 52분 

<br>

## 문제 요구 사항
모든 요소가 유일한 양의 정수 배열 nums가 주어집니다.
- 2 <= nums.length <= 14
- 1 <= nums[i] <= 1,000,000,000

'특별한 순열'의 조건은 다음과 같습니다.
- nums[i] % nums[i+1] == 0 OR nums[i+1] % nums[i] ==0

주어진 배열로 순열을 만들었을 때, '특별한 순열'의 전체 개수를 반환하는 문제입니다. 정답이 너무 크다면 10^9 +7 모듈로 연산을 수행하고 반환합니다.

<br>

## 풀이
백트래킹으로 가능한 순열을 순회하면 최대 14! 경우의 수를 계산해야 하므로 시간 초과가 예상됩니다. <br>
효율적인 풀이를 위해 비트마스킹과 DP를 활용합니다.
- dp[mask][last]: mask에 포함된 정수 사용, 마지막으로 사용한 숫자의 인덱스가 last일 때 만들 수 있는 순열의 개수

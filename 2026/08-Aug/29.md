# 2026-08-29 TIS
## 타이틀: [Binary Gap](https://leetcode.com/problems/binary-gap/description/)
> 풀이 시간: 6분 

<br>

## 문제 요구 사항
양의 정수 n이 주어집니다.
- 1 <= n <= 1,000,000,000

n을 비트로 표현했을 때, 두 개의 비트1 사이에서 가장 긴 거리를 반환하는 문제입니다.

<br>

## 풀이
1. 정수 n을 비트 문자열로 변환
2. 비트 문자열 순회하면서 비트1인 인덱스 저장
    - 리스트에 저장된 인덱스가 1개 이하라면 0 반환
3. 리스트 순회하면서 인접 요소 사이의 인덱스 차이를 최댓값에 갱신
4. 최댓값 반환

# 2026-08-27 TIS
## 타이틀: [Subarray Sums Divisible by K](https://leetcode.com/problems/subarray-sums-divisible-by-k/description/)
> 풀이 시간: 38분 

<br>

## 문제 요구 사항
정수 배열 nums가 주어집니다.
- 1 <= nums.length <= 30,000
- -10,000 <= nums[i] <= 10,000

정수 k가 주어집니다.
- 2 <= k <= 10,000

k로 나눠떨어지는 nums의 연속된 부분 배열의 합의 개수 반환하는 문제입니다.

<br>

## 풀이
누적합 배열을 구했을 때 k로 나눠지는 부분 배열의 합을 식으로 표현하면 다음과 같습니다.
- (sum[j] - sum[i-1]) % k == 0

해당 수식을 변형하면,
- sum[j] % k == sum[i-1] % k
- 또는, sum[j] % k == 0

이를 활용하여, 누적합 배열을 할당하고 각 누적합의 k로 나눈 나머지를 카운팅하여 풀이했습니다.

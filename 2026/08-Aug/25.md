# 2026-08-25 TIS
## 타이틀: [Sort List](https://leetcode.com/problems/sort-list/description/)
> 풀이 시간: 8분 

<br>

## 문제 요구 사항
연결리스트 head 노드가 주어졌을 때 오름차순 정렬해서 head를 반환하는 문제입니다.
- 0 <= 노드 개수 <= 50,000
- -10,000 <= val <= 10,000

<br>

## 풀이
주어진 연결리스트를 순회하며 리스트 컬렉션에 담고 내장 정렬 메서드를 통해 정렬합니다. 그리고 할당한 리스트를 순회하며 새 연결리스트를 생성하고 head를 반환하여 풀이했습니다.

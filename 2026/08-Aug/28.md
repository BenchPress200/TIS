# 2026-08-28 TIS
## 타이틀: [K-th Smallest Prime Fraction](https://leetcode.com/problems/k-th-smallest-prime-fraction/description/)
> 풀이 시간: 15분 

<br>

## 문제 요구 사항
정수 배열 arr가 주어집니다.
- 2 <= arr.length <= 1,000
- 1 <= arr[i] <= 30,000
- arr[0] == 1
- 1과 소수로 이루어지고, 모든 요소 유니크
- 오름차순 정렬된 상태

정수 k가 주어집니다. 여기서 모든 i와 j는 0 <= i < j < arr.length일 때, 분수 arr[i] / arr[j] 계산하고 k번째로 작은 분수의 분자, 분모 반환하는 문제입니다.

<br>

## 풀이
입력의 크기가 작기 때문에 arr를 이중 순회하여 모든 경우의 수를 구합니다. 
1. Fraction 클래스 정의
    - 분자
    - 분모
    - 분수(실수 타입)
2. 정렬 기준은 분수 오름차순
3. arr 이중 순회하면서 Fraction 리스트 저장
4. Fraction 리스트 오름차순 정렬 및 k 번째 요소 조회 및 반환

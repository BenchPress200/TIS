# 2026-08-24 TIS
## 타이틀: [Design Add and Search Words Data Structure](https://leetcode.com/problems/design-add-and-search-words-data-structure/description/)
> 풀이 시간: 52분 

<br>

## 문제 요구 사항
단어 사전 클래스가 주어집니다.
- WordDictionary: 생성자
- void addWord(String word): 단어 추가
- boolean search(String word): 단어 유무 확인
- 1 <= word.length <= 25
- word는 영어 소문자로 이루어짐
- search 메서드에서 word는 최대 2개 '.' 가능
    - '.'은 모든 문자 매칭
- addWord와 search 콜은 최대 10,000

해당 클래스를 정의하는 문제입니다.

<br>

## 풀이
효율적인 단어 유무 탐색을 위해 트라이 를 활용했고, 중간에 '.'로 전체 탐색이 가능하기 때문에 재귀 형태의 dfs를 결합하여 풀이했습니다.

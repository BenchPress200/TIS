# 2026-08-31 TIS
## 타이틀: [Longest ZigZag Path In a Binary Tree](https://leetcode.com/problems/longest-zigzag-path-in-a-binary-tree/description/)
> 풀이 시간: 16분 

<br>

## 문제 요구 사항
이진 트리 루트 노드가 주어집니다.
- 1 <= 노드 수 <= 10,000
- 1 <= Node.val <= 100

지그재그 경로는 다음과 같습니다.
1. 트리에서 아무 노드나 선택
2. 현재 노드에서 방향이 오른쪽이면 오른쪽 자식을, 왼쪽이면 왼쪽 자식으로 이동
3. 자식으로 이동했을 때 방향 전환
4. 다음 자식 노드로 이동할 수 없을 때까지 반복

지그재그 경로의 길이는 [방문한 노드 수-1]이라고 했을 때, 가장 긴 지그재그 경로 길이 반환하는 문제입니다.

<br>

## 풀이
루트부터 재귀형태로 DFS를 진행합니다. 이전 이동 방향과 그에 따른 지그재그 경로 길이를 전달하면서 갱신하여 풀이했습니다.

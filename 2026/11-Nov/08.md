# 2026-11-08 TIS
## 타이틀: [Check if Binary String Has at Most One Segment of Ones](https://leetcode.com/problems/check-if-binary-string-has-at-most-one-segment-of-ones/description/)
> 풀이 시간: 11분 

<br>

## 문제 요구 사항
이진수 문자열 s가 주어집니다.
- 1 <= 길이 <= 100

비트 1들의 연속을 하나의 세그먼트로 보는데, 이 세그먼트가 최대 한 개만 존재한다면 true 반환하는 문제입니다.

<br>

## 풀이
s의 문자를 순회합니다.
1. 이전 비트가 '0'이고 다음 비트가 '1'인 곳 개수 카운팅
2. 카운트가 2 이상이라면 false 반환, 그렇지 않다면 true 반환

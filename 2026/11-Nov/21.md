# 2026-11-21 TIS
## 타이틀: [Minimum Distance to the Target Element](https://leetcode.com/problems/minimum-distance-to-the-target-element/description/)
> 풀이 시간: 7분 

<br>

## 문제 요구 사항
정수 배열 nums이 주어집니다.
- 1 <= 길이 <= 1,000
- 1 <= 값 <= 10,000

정수 target이 주어집니다.
- nums[i] 값 중 하나

정수 start이 주어집니다.
- 0 <= start <= nums.length

다음 조건을 만족하는 abs를 반환합니다.
- nums[i] == target
- abs(i - start) 최솟값

<br>

## 풀이
nums의 길이가 1,000이므로 순회하여 nums[i] == target 이면 abs의 최솟값을 확인하고 갱신하여 풀이합니다.

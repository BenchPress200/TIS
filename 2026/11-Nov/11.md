# 2026-11-11 TIS
## 타이틀: [Count Stable Subarrays](링https://leetcode.com/problems/count-stable-subarrays/description/크)
> 풀이 시간: 72분 

<br>

## 문제 요구 사항
정수 배열 nums가 주어집니다.
- 1 <= 길이 <= 100,000
- 1 <= nums[i] <= 100,000

nums의 부분 배열이 'stable'이 될 수 있는 조건은 다음과 같습니다.
- !(i < j && nums[i] > nums[j])

2차원 정수 배열 queries가 주어집니다.
- 1 <= 길이 <= 100,000
- quries[i] = [l, r]
- 0 <= l <= r <= nums.length - 1

querues의 각 요소들에 대해서 계산하는데, nums[l...r] 내에 있는 'stable' 부분 배열의 개수를 정답 배열에 저장해서 반환하는 문제입니다. 요소가 하나라도 stable 부분 배열로 취급
합니다.

<br>

## 풀이
'stable' 조건은 부분 배열이 단조 증가입니다.
- 인접한 원소에 대해 nums[i] <= nums[i+1]

쿼리마다 구간을 직접 탐색하면 시간 초과 예상되기 때문에 Stable 구간의 개수를 누적합으로 전처리합니다.
1. 누적합 배열 stable 할당
    - stable[i+1]: 인덱스 0부터 i까지의 Stable 구간의 총개수
    - count: 현재 인덱스 i에서 끝나는 Stable 구간의 개수
    - 이전 원소보다 작다면 count = 1
    - 이전 원소 이상이라면 count++
    - stable[i+1] = stable[i] + count
2. 쿼리 [l, r] 처리
    - l 이전에 시작한 부분 배열까지 포함되기 때문에 stable[r+1] - stable[l]만으로는 계산 불가능
    - l부터 비감소가 유지되는 마지막 인덱스 end 탐색
    - 누적합의 증가 패턴을 이용한 이분 탐색
    - [l, end] 구간의 Stable 구간 개수
        - 길이 k = end-l+1
        - k*(k+1)/2
    - [end+1, r] 구간의 Stable 구간 개수
    - stable[r+1] - stable[end+1]
    - 두 구간의 개수 합산하여 정답 계산

# 2026-11-04 TIS
## 타이틀: [제목](https://leetcode.com/problems/minimum-queen-moves-to-reach-target/description/)
> 풀이 시간: 17분 

<br>

## 문제 요구 사항
8 * 8 체스판과 퀸 존재합니다.<br>
퀸 시작 위치 source가 주어집니다.
- source = [sr, sc]

퀸 도착 위치 targetrk 가 주어집니다.
- target = [tr, tc]

퀸은 한 번 이동할 때, 행, 렬, 대각선으로 한 칸 이상 이동 가능합니다. 이때, 퀸이 target으로 가기 위한 최소한의 이동 횟수 반환하는 문제입니다.

<br>

## 풀이
퀸의 이동 특성상 한 번 혹은 두 번의 이동으로 타겟 도달 가능합니다. 이미 도달했다면 이동 안 해도 됩니다.
1. 현재 위치가 타겟 위치인지 확인 -> 0 반환
2. 현 위치 기준 같은 행, 렬, 대각선인지 확인 -> 1 반환
3. 나머지 -> 2 반환

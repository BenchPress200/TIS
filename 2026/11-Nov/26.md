# 2026-11-26 TIS
## 타이틀: [N-Repeated Element in Size 2N Array](https://leetcode.com/problems/n-repeated-element-in-size-2n-array/description/)
> 풀이 시간: 10분 

<br>

## 문제 요구 사항
정수 배열 nums이 주어집니다.
- nums의 길이 == 2*n
- 2 <= n <= 5,000
- 0 <= nums[i] <= 10,000
- n+1개의 유니크 값 존재
- n개는 정확히 한 번씩 등장
- 하나의 원소만 n번 반복해서 등장

반복해서 n번 등장하는 원소 반환하는 문제입니다.

<br>

## 풀이
정답으로 반환할 요소만 2번 이상 등장하니까 해시셋으로 확인합니다.
1. 해시셋 선언
2. nums 순회
3. 해시셋에 없는 값이면 넣고, 있는 값이면 해당 요소 반환

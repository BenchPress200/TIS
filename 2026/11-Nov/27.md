# 2026-11-27 TIS
## 타이틀: [Make Array Zero by Subtracting Equal Amounts](https://leetcode.com/problems/make-array-zero-by-subtracting-equal-amounts/description/)
> 풀이 시간: 12분 

<br>

## 문제 요구 사항
음이 아닌 정수 배열 nums가 주어집니다.
- 1 <= 길이 <= 100
- 0 <= nums[i] <= 100

한 번의 연산 정의는 다음과 같습니다.
1. 0이 아닌 가장 작은 값 x 선택
2. nums의 모든 양의 정수로부터 x 빼기

num의 모든 요소를 0으로 만들기 위해 수행하는 최소 연산 횟수 반환하는 문제입니다.

<br>

## 풀이
1. 연산 횟수 변수 선언
2. 모든 요소가 0일 때까지 while
    1. 가장 작은 수 x 찾기
    2. 모든 양의 정수에서 x 빼기
    3. 연산 횟수++
3. 연산 횟수 반환

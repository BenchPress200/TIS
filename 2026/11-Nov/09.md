# 2026-11-09 TIS
## 타이틀: [Minimum Removals to Balance Array](https://leetcode.com/problems/minimum-removals-to-balance-array/description/)
> 풀이 시간: 25분 

<br>

## 문제 요구 사항
정수 배열 nums가 주어집니다.
- 1 <= 길이 <= 100,000
- 1 <= nums[i]< = 1,000,000,000

정수 k가 주어집니다.
- 1 <= k <= 100,000

배열의 'balanced' 조건은 다음과 같습니다.
- 최댓값이 기껏해야 최소값의 k배

조건을 맞추기 위해서 요소 제거 가능하다고 할 때, 최소 제거 수를 반환하는 문제입니다.

<br>

## 풀이
1. 최댓값과 최솟값을 알아야 하므로 nums 오름차순 정렬
    - 제일 앞 또는 뒤에 요소를 제거해서 balanced 만족시켜야 함
2. 요소 순회하면서, 제거해야할 뒷쪽 수를 이분탐색 (NlogN)
3. 뒷쪽 수 탐색 완료할 때마다 제거하는 요소 개수 갱신
    - k배 했을 때 int 범위 넘어가니까 long 사용
4. 최소 제거 수 반환

# 2026-11-20 TIS
## 타이틀: [Convert 1D Array Into 2D Array](https://leetcode.com/problems/convert-1d-array-into-2d-array/description/)
> 풀이 시간: 14분 

<br>

## 문제 요구 사항
정수 배열 original이 주어집니다.
- 1 <= 길이 <= 50,000
- 1 <= original[i] <= 10,000

정수 m, n이 주어집니다.
- 1 <= m, n <= 40,000

original을 m * n 이차원 배열에 순차적으로 담아서 반환하는 문제입니다. 이차원 배열에 딱 맞아 떨어지지 않는다면 빈 배열 반환합니다.

<br>

## 풀이
1. original의 요소 개수와 m * n 개수 비교
    - 다르다면 빈 배열 반환
2. m * n 이차원 배열 선언
3. original 순회하면서 m마다 행과 열 계산해서 이차원 배열에 할당
4. 이차원 배열 반환

# 2026-11-22 TIS
## 타이틀: [Maximum Number of Words You Can Type](https://leetcode.com/problems/maximum-number-of-words-you-can-type/description/)
> 풀이 시간: 4분 

<br>

## 문제 요구 사항
문자열 text가 주어집니다.
- 1 <= 길이 <= 10,000
- 띄어쓰기 하나로 구분된 단어들

문자열 brokenLetters가 주어집니다.
- 영어 소문자로 이루어짐
- 0 <= 길이 <= brokenLetters

brokenLetters에 있는 문자는 입력을 못 한다고 했을 떄, text에서 완전히 입력할 수 있는 단어의 수를 반환하는 문제입니다.

<br>

## 풀이
0. 입력 가능한 단어 카운팅 변수 선언
1. text를 띄어쓰기 기준으로 배열에 단어 저장
2. brokenLetters 문자를 해시셋에 저장
3. 해당 배열 순회하면서 타이핑 가능한지 확인
    - 해시셋에 포한된 문자가 있는지 확인
4. 카운팅 변수 반환

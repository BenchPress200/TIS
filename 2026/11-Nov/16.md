# 2026-11-16 TIS
## 타이틀: [Power of Three](https://leetcode.com/problems/power-of-three/description/)
> 풀이 시간: 4분 

<br>

## 문제 요구 사항
정수 n이 주어집니다.
- -2^31 <= n <= 2^31 - 1

n이 3의 제곱수라면 true를 반환하는 문제입니다.

<br>

## 풀이
1. n이 0이하라면 false 반환
2. n이 1이 될 때까지 3으로 나눠떨어지는지 확인
    - 1이 되었다면, true 반환
    - 그렇지 않다면, false 반환

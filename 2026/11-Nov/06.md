# 2026-11-06 TIS
## 타이틀: [Find Champion 1](https://leetcode.com/problems/find-champion-i/description/)
> 풀이 시간: 5분 

<br>

## 문제 요구 사항
n개의 팀이 존재하고 팀의 번호는 0 ~ n-1입니다.<br>
n * n 사이즈의 2차원 배열 grid이 주어집니다.
- 2 <= n <= 100
- grid[i][j]: 0 or 1, 1이면 j팀보다 i팀이 더 강함

격자를 보고 가장 강한 팀 번호 반환하는 문제입니다.

<br>

## 풀이
가장 강한 팀은 본인 번호를 제외한 모든 인덱스에 1을 가집니다.
1. 팀 번호 0부터 n-1까지 순회
2. 자기 자신을 제외한 모든 팀에서 grid[i][j] == 1 인지 확인하고, 찾으면 즉시 팀 번호 반환

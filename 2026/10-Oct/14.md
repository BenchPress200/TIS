# 2026-10-14 TIS
## 타이틀: [Restore IP Addresses](https://leetcode.com/problems/restore-ip-addresses/description/)
> 풀이 시간: 36분 

<br>

## 문제 요구 사항
문자열 s가 주어집니다.
- 1 <= 길이 <= 20
- s는 숫자로 이루어짐

문자열 사이에 '.' 세 개를 찍었을 때, 유효한 IP 표현을 순서 상관없이 반환하는 문제입니다.

<br>

## 풀이
유효한 IP 조건은 다음과 같습니다.
- IPv4 기준 4개의 파트로 구분됨
- 각 파트는 0 ~ 255로 표현
- s의 최소 길이 4, 최대 길이 12일 때만 가능

최대 길이 12일 때 '.' 찍을 수 있는 곳은 11개이므로 여기서 겹치지 않는 3개의 위치를 백트래킹으로 선택하여 풀이합니다.

0. 문자열 길이 검증하고 유효하지 않다면 빈 문자열 반환
1. 정답 리스트 선언
2. 스택 선언 (문자열의 문자 인덱스 i: char[i] 바로 다음 위치에 올 '.' 위치)
3. 백트래킹 수행
    1. 스택에 '.' 인덱스 3개가 담겼다면 IP 만들고 유효성 검사 후 정답 리스트 추가 및 return
    2. 아니라면, 이전 다음 탐색 위치부터 '.'을 인덱스 스택에 담고 백트래킹 재귀 호출
4. 정답 리스트 반환

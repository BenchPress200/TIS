# 2026-10-28 TIS
## 타이틀: [Find if Path Exists in Graph](https://leetcode.com/problems/find-if-path-exists-in-graph/description/)
> 풀이 시간: 9분 

<br>

## 문제 요구 사항
n개의 정점을 가진 그래프 존재합니다.
- 1 <= n <= 200,000
- 정점의 번호는 0부터 n-1

양방향 간선 정보 edges 주어집니다.
- 0 <= 길이 <= 200,000
- edges[i]: [u, v] (양방향 연결임)

source에서 destination으로 가는 경로가 있는지 판단하고 결과 반환하는 문제입니다.

<br>

## 풀이
1. edges로 그래프 할당
2. 방문 표시 배열 할당
3. source부터 BFS진행
4. destination 방문 여부 반환

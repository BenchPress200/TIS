# 2026-10-22 TIS
## 타이틀: [Sign of the Product of an Array](https://leetcode.com/problems/sign-of-the-product-of-an-array/description/)
> 풀이 시간: 12분 

<br>

## 문제 요구 사항
정수 배열 nums가 주어집니다.
- 1 <= 길이 <= 1,000
- -100 <= nums[i] <= 100

`signFunc(x)` 메서드 구현합니다.
- x가 양수라면 1 반환
- x가 음수라면 -1 반환
- x가 0이라면 0 반환

nums의 모든 값을 곱하고 해당 값을 `signFunc`으로 전달해서 반환하는 문제입니다.

<br>

## 풀이
모든 값을 곱했을 때 언더 혹은 오버플로우가 발생 가능합니다. 따라서 양수, 음수, 0의 특성 고려해서 풀이합니다.
1. nums에 음수, 양수, 0의 개수 카운팅
2. 해당 개수를 판정하는 `signFunc`으로 전달 및 반환
    - 0이 하나 이상이라면 0반환
    - 음수의 개수가 홀수라면 -1 반환
    - 그렇지 않다면 1 반환

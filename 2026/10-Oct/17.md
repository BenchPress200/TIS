# 2026-10-17 TIS
## 타이틀: [Pyramid Transition Matrix](https://leetcode.com/problems/pyramid-transition-matrix/description/)
> 풀이 시간: 57분 

<br>

## 문제 요구 사항
바닥 블록을 나타내는 문자열 bottom가 주어집니다.
- 2 <= 길이 <= 6
- A ~ F로 이루어짐

블록을 피라미드로 쌓는 패턴을 담은 문자열 배열 allowed가 주어집니다.
- 0 <= 길이 <= 216
- allowed[i].length == 3
- 'A' <= allowed[i] <= 'F'
- 모든 값 유니크

주어진 bottom로 시작해 allowed에 존재하는 패턴으로 블록을 쌓았을 때, 피라미드 완성 여부 반환하는 문제입니다.

<br>

## 풀이
1. 패턴 저장
    - allowed의 각 패턴을 map[6][6]에 저장
    - 인접한 두 블록을 기준으로 그 위에 올릴 수 있는 문자들 관리

2. 백트래킹 시작
    - 주어진 bottom을 기준으로 다음 층 생성
    - 현재 층의 길이가 1이라면 피라미드가 완성된 것이므로 true를 반환

3. 다음 층의 블록 생성
    - 현재 층의 인접한 두 블록을 왼쪽부터 순서대로 확인
    - map에서 올릴 수 있는 문자 하나 선택하여 next에 추가
    - 재귀 호출로 다음 위치의 블록을 생성

4. 다음 층 완성 시 재귀 탐색
    - next.length() == bottom.length() - 1이면 다음 층이 완성
    - 완성된 next를 새로운 bottom으로 사용하여 백트래킹을 수행

5. 메모이제이션으로 중복 탐색 방지
    - HashSet에 이미 피라미드 완성에 실패한 bottom을 저장
    - 동일한 bottom이 다시 등장하면 탐색하지 않고 false를 반환

6. 백트래킹 및 조기 종료
    - 선택한 문자로 피라미드를 완성하지 못했다면 해당 문자를 제거하고 다른 문자 시도
    - 하나라도 피라미드를 완성하면 즉시 true를 반환

7. 최종 결과 반환
    - 모든 가능한 조합을 탐색했는데도 완성하지 못했다면 false를 반환

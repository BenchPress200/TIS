# 2026-10-05 TIS
## 타이틀: [Tree of Coprimes](https://leetcode.com/problems/tree-of-coprimes/description/)
> 풀이 시간: 122분 

<br>

## 문제 요구 사항
트리 정보가 주어집니다.
- n개의 노드
- 1 <= n <= 100,000
- 0 <= 노드 번호 <= n-1
- n-1개의 간선 존재
- 루트 노드는 0번

정수 배열 nums가 주어집니다.
- nums[i]: i번째 노드의 값
- 1 <= nums[i] <= 50

간선 정보 edges가 주어집니다.
- edges[j] = [u, v]: 노드 u와 v 사이의 간선

`coprime` 만족 조건은 다음과 같습니다.
- 두 노드의 값 x와 y의 GCD가 1일 경우

노드 i의 조상 정의는 다음과 같습니다.
- 노드 i부터 root까지 최단 경로에 존재하는 다른 노드

각 노드의 가장 가까우면서 `coprime`을 만족하는 노드 번호를 찾아서 배열로 반환하는 문제입니다. 해당하는 조상이 없다면 -1을 할당합니다.

<br>

## 풀이
0번 노드부터 순회하면서 조상 탐색하고 coprime 검증하게 되면, 모든 노드에 대해서 그래프 탐색을 진행하므로 O(n^2) 시간 초과 발생합니다. 노드의 값 범위가 1 ~ 50임을 활용하여 O(n*50)으로 풀이합니다.
1. edges 정보로 그래프 생성
2. 루트부터 DFS 진행
3. 각 노드는 1부터 50 중에서 값을 가지는 조상 노드 번호와 깊이를 저장
    - 가까울수록 DFS하면서 덮어쓰기 됨
4. 현재 탐색 노드에서 1부터 50까지 순회하면서 gcd 만족하고, 가장 가까운 조상 노드 찾아서 할당

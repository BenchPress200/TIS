# 2026-10-19 TIS
## 타이틀: [Minimum Number of Operations to Make Arrays Similar](https://leetcode.com/problems/minimum-number-of-operations-to-make-arrays-similar/description/)
> 풀이 시간: 26분 

<br>

## 문제 요구 사항
양의 정수 배열 nums와 target가 주어집니다.
- 1 <= 길이 <= 10,000
- 1 <= nums[i], target[i] <= 1,000,000

가능한 연산 정의는 아래와 같습니다.
- 구분된 인덱스 i와 j 선택
- nums[i] = nums[i] + 2
- nums[j] = nums[j] - 2

`similar`의 정의는 아래와 같습니다.
- 두 배열의 각 요소 빈도수가 동일해야 함

nums와 target이 `similar`가 되는 최소 연산 횟수 반환하는 문제입니다. nums는 target으로 반드시 만들 수 있다고 가정합니다.

<br>

## 풀이
변환 연산은 +-2이기 때문에 짝수는 짝수로, 홀수는 홀수로 만 변환 가능합니다. 따라서, 홀수와 짝수를 분리해서 생각해야 합니다.<br>
각각 정렬해서 작은 값부터 매칭하여 연산 횟수 기록합니다. 작은 값부터 매칭 안 해도 되지만, 작은 값부터 매칭할 경우 연산 횟수가 늘어날 수 있습니다.(작은 값도 반드시 맞춰줘야 하므로)
1. nums와 target을 홀수, 짝수 리스트로 각각 분리
2. 모든 리스트 오름차순 정렬
3. 짝수 nums, target 리스트 비교하면서 연산 횟수 누적
4. 홀수 nums, target 리스트 비교하면서 연산 횟수 누적
5. 총 연산 횟수 반환

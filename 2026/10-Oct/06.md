# 2026-10-06 TIS
## 타이틀: [Minimize Malware Spread 2](https://leetcode.com/problems/minimize-malware-spread-ii/description/)
> 풀이 시간: 53분 

<br>

## 문제 요구 사항
n개의 노드가 존재합니다.
- n개의 노드는 최대 n * n의 네트워크 이룸
- 2 <= n <= 300

노드의 네트워크 정보 graph가 주어집니다.
- graph[i][j] == 1: 노드 i와 j는 직접 연결되어 있음
- n == graph.length
- n == graph[i].length
- graph[i][j] == graph[i][j]

초기 감염 노드를 나타내는 initial이 주어집니다.
- 1 <= initial.length < n
- 0 <= initial[i] <= n-1
- 모든 값은 유일

두 노드가 직접적으로 연결되어 있고 둘 중 하나라도 감염되어 있다면 두 노드 모두 감염됩니다. 이러한 감염은 불가능할 때까지 퍼질 경우, initial로부터 정확히 하나의 노드를 제외시켰을 때 최종 감염된 노드를 최소화시키는 노드 번호 반환하는 문제입니다.해당 노드가 다수라면 제일 작은 번호 반환합니다.

<br>

## 풀이
1. 총 감염 최솟값 중 가장 작은 번호 노드를 유지하기 위해 initial 오름차순 정렬
2. initial에 존재하는 노드 한 번씩 제거한 그래프 생성 및 BFS 수행
3. 총 감염 노드가 최솟값이라면 갱신 및 제거한 노드 번호 저장

# 2026-10-08 TIS
## 타이틀: [Path with Maximum Probability](https://leetcode.com/problems/path-with-maximum-probability/description/)
> 풀이 시간: 21분 

<br>

## 문제 요구 사항
n개의 노드를 가지는 무방향 가중치 그래프 존재가 존재합니다.
- 2 <= n <= 10,000

간선 정보 edges가 주어집니다.
- edges[i] = [a, b]: a와 b연결

간선 순회 가능성 succProb가 주어집니다.
- succProb[i]: edges[i]간선의 순회 가능성

시작 노드와 도착 노드가 주어졌을 때, 시작부터 도착 경로까지 가능한 최대 순회 가능성 반환하는 문제입니다. 경로가 없다면 0 반환합니다.

<br>

## 풀이
1. 시작노드부터 다익스트라 수행
2. 모든 노드의 도착 가능성 0으로 초기화
3. 다음 탐색 노드가 현재 가능성보다 낮다면 확률 갱신하고 큐에 삽입
4. 도착지 확률 반환

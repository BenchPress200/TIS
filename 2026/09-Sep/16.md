# 2026-09-16 TIS
## 타이틀: [Sum of Distances](https://leetcode.com/problems/sum-of-distances/description/)
> 풀이 시간: 70분 

<br>

## 문제 요구 사항
정수 배열 nums가 주어집니다.
- 1 <= 길이 <= 100,000
- 0 <= nums[i] <= 1,000,000,000

nums와 길이가 같은 배열 arr 존재합니다
- arr[i]: nums[i] == nums[j] && i != j를 만족하는 모든 j에 대해서 |i-j|의 합
- 위 조건을 만족하는 j가 없다면 0

해당 arr를 구해서 반환하는 문제입니다.

<br>

## 풀이
1. nums 한 번 순회하면서 [값: 인덱스]쌍으로 해시맵 저장
2. 해시맵에 저장된 인덱스 리스트는 각각 오름차순 인덱스니까, 특정 인덱스에 대한 좌우 누적합을 구해서 상대적인 거리 도출 가능

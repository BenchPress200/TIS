# 2026-09-01 TIS
## 타이틀: [Populating Next Right Pointers in Each Node 2](https://leetcode.com/problems/populating-next-right-pointers-in-each-node-ii/description/)
> 풀이 시간: 10분 

<br>

## 문제 요구 사항
이진 트리의 루트 노드가 주어집니다.
- 0 <= 노드 수 <= 6,000
- -100 <= Node.val <= 100

각 노드의 오른쪽 노드(자식 x)를 찾아서 할당하는 문제입니다. 오른쪽 노드가 없다면 NULL을 유지합니다.

<br>

## 풀이
1. 루트를 시작으로 BFS
2. 같은 레벨에서 왼쪽 -> 오른쪽 순으로 리스트에 방문 노드 담기
3. 한 레벨 탐색이 끝났을 때 리스트 순회하면서 오른쪽 노드 할당

# 2026-09-02 TIS
## 타이틀: [Minimum Time to Repair Cars](https://leetcode.com/problems/minimum-time-to-repair-cars/description/)
> 풀이 시간: 35분 

<br>

## 문제 요구 사항
정수 배열 ranks가 주어집니다.
- 1 <= ranks.length <= 10,000
- 1 <= ranks[i] <= 100
- ranks[i]: i번째 정비사의 랭크
- 랭크 r을 가진 정비사는 n대의 차를 r*n^2분 동안 수리

정수 cars가 주어집니다.
- 1 <= cars <= 100,000
- 수리를 기다리는 모든 차의 수

모든 차를 수리하는 데 걸리는 최소 시간 반환하는 문제입니다. 모든 정비사들은 동시에 작업 가능합니다.

<br>

## 풀이
특정 시간이 주어졌을 때 처리할 수 있는 차의 수는 정해져있습니다. 가능한 처리 시간 범위는 다음과 같습니다.
- 0 <= 처리 가능 시간 <= minRank * n * n (100 * 100,000 * 100,000)

따라서 처리 가능 시간을 이분탐색하며 각 정비사가 탐색할 시간에 처리할 수 있는 차의 수를 합산해 풀이했습니다.

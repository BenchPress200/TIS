# 2026-09-03 TIS
## 타이틀: [Minimum Cost to Make at Least One Valid Path in a Grid](https://leetcode.com/problems/minimum-cost-to-make-at-least-one-valid-path-in-a-grid/description/)
> 풀이 시간: 46분 

<br>

## 문제 요구 사항
m * n 크기 grid가 주어집니다.
- 1 <= m, n <= 100
- 1 <= grid[i][j] <= 4

각 셀이 가지는 값은,
- 1: 다음 이동 오른쪽
- 2: 다음 이동 왼쪽
- 3: 다음 이동 아래쪽
- 4: 다음 이동 위쪽

초기에 좌측 상단에서 시작합니다. 유효 경로는 좌측 상단에서 시작해서 오르쪽 하단으로 가는 경로입니다. 유효한 경로가 최단 경로여야만 하는 것은 아닙니다. 한 번에 하나의 셀에 있는 사인 수정 가능하고 비용이 1입니다. 

주어진 격자에서 최소한 하나의 유효 경로가 있도록 만드는 최소 비용 반환하는 문제입니다.

<br>

## 풀이
격자랑 동일한 크기의 최소 비용 배열과 BFS를 활용하여 풀이했습니다. BFS 이동하면서 현재 방향과 grid의 방향을 보고 비용을 책정했고, 갱신 비용이 더 저렴할 경우 갱신하고 큐에 넣어 탐색했습니다.

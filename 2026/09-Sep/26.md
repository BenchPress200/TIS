## 타이틀: [Number of Intersecting Interval Pairs 1](https://leetcode.com/problems/number-of-intersecting-interval-pairs-i/description/)
> 풀이 시간: 29분 

<br>

## 문제 요구 사항
2차원 배열 intervals이 주어집니다.
- 2 <= interval.length <= 100
- intervals[i] = [start, end]
- 0 <= start <= end <= 100

0 <= i < j < n을 만족하는 interval[i], interval[j]의 교집합이 존재하는 i,j 쌍의 개수 반환하는 문제입니다.

<br>

## 풀이
1. 카운트 변수 선언
2. 이중 반복문 순회하면서 겹치는 구간 확인

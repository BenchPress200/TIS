## 타이틀: [Count Unreachable Pairs of Nodes in an Undirected Graph](https://leetcode.com/problems/count-unreachable-pairs-of-nodes-in-an-undirected-graph/description/)
> 풀이 시간: 23분 

<br>

## 문제 요구 사항
정수 n이 주어집니다.
- n개의 노드로 이루어진 무방향 그래프 존재
- 노드의 번호는 0 ~ n-1
- 1 <= n <= 100,000

2차원 배열 edges가 주어집니다.
- edges[i] = [a, b]: a노드와 b노드 연결
- 0 <= edges.length <= 200,000

서로 도달할 수 없는 노드 쌍의 개수 반환하는 문제입니다.

<br>

## 풀이
1. 방문 배열 선언
2. 그래프 초기화
3. BFS하면서 각 탐색마다 방문 노드 개수 반환
4. 현재 탐색에서 도달 불가능한 쌍의 개수 = (전체노드 - 방문노드) * 방문노드
5. 탐색마다 나온 쌍의 개수를 누적하고 겹치는 경우를 제외하기 위해 나누기 2 수행 후 반환

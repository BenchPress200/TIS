# 2026-09-18 TIS
## 타이틀: [Check Knight Tour Configuration](https://leetcode.com/problems/check-knight-tour-configuration/description/)
> 풀이 시간: 19분 

<br>

## 문제 요구 사항
n * n 체스판이 있습니다.
- 3 <= n <= 7

유효한 설정이라면,
- 나이트가 왼쪽 상단에서 시작
- 체스판에 모든 칸을 정확히 한 번 방문
- 나이트는 현재 위치 기준으로 수직2-수평1 또는 수직1-수평2 칸 이동 가능(총 8가지)

체스판 각 칸은 구분된 정수를 가지는데,
- 0 <= grid <= n*n-1
- 해당 정수 grid[row][col]은 나이트의 방문 순번

주어진 격자에서 나이트의 움직임이 유효한지, 모든 칸을 방문할 수 있는지 검증하는 문제입니다.

<br>

## 풀이
1. 여덟 방향 가리킬 배열 선언
2. 0부터 시작해서 다음 숫자가 이동 범위에 있는지 확인
3. 마지막 순번에 도달하면 true, 아니라면 false 반환

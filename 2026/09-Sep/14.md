# 2026-09-14 TIS
## 타이틀: [Find the Maximum Number of Marked Indices](https://leetcode.com/problems/find-the-maximum-number-of-marked-indices/)
> 풀이 시간: 49분 

<br>

## 문제 요구 사항
정수 배열 nums이 주어집니다.
- 1 <= 길이 <= 100,000
- 1 <= nums[i] <= 100,000,000

초기에 인덱스들은 모두 표시하지 않은 상태로 간주합니다. 다음 연산을 횟수 제한없이 적용 가능합니다.
- 표시되지 않은 서로 다른 인덱스 i와 j를 선택하고, 2*nums[i] <= nums[j]라면 둘 다 표시

nums에서 최대 표시 개수 반환하는 문제입니다.

<br>

## 풀이
조건을 만족하는 짝을 최대한 많이 찾는 문제입니다.
1. 크기에 따라 짝을 정할 수 있으므로 nums를 오름차순 정렬
2. i를 시작인덱스, j를 중간 이후 인덱스로 선택해서 투 포인터 탐색 후 표시 카운팅
    - 어차피 짝의 최대 수는 정해져 있음 => j는 절반 이후 인덱스부터 시작
    - 절반 이후에서 i, j를 선택해서 표시할 수 있다면 절반 이전 i와 절반 이후 j 선택해서도 가능
3. 표시 수 반환

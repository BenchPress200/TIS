# 2026-09-08 TIS
## 타이틀: [Count Visited Nodes in a Directed Graph](https://leetcode.com/problems/count-visited-nodes-in-a-directed-graph/description/)
> 풀이 시간: 48분 

<br>

## 문제 요구 사항
n개의 노드로 이루어진 방향 그래프가 있습니다.
- 0 <= 노드번호 <= n-1
- 2 <= n <= 100,000

n개의 간선 edges 리스트가 주어집니다.
- edges[i]: 노드 i -> node edges[i]

각 노드를 시작으로 간선을 통해 다른 노드를 방문하는데, 방문했던 노드를 발견할 때까지 진행합니다.각 이때 노드마다 방문하는 노드의 개수 담아서 배열로 반환하는 문제입니다.

<br>

## 풀이
각 노드마다 상태를 기록하는 배열을 두고, 재방문한 노드가 시작 노드인지, 현재 경로에 있는지, 이미 계산된 결과를 가진 노드인지 판단하여 풀이했습니다.

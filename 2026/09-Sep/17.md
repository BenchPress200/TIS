# 2026-09-17 TIS
## 타이틀: [Find Indices With Index and Value Difference 2](https://leetcode.com/problems/find-indices-with-index-and-value-difference-ii/description/)
> 풀이 시간: 55분 

<br>

## 문제 요구 사항
정수 배열 nums이 주어집니다.
- 1 <= 길이 <= 100,000
- 0 <= nums[i] <= 1,000,000,000

선택한 두 인덱스의 차이 indexDifference 변수가 주어집니다.
- 0 <= indexDifference <= 100,000

선택한 두 인덱스의 값 차이 valueDifference 변수가 주어집니다.
- 0 <= valueDifference <= 100,000

다음 두 조건을 만족하는 인덱스 쌍 찾는 문제입니다.             
- abs(i-j) >= indexDifference
- abs(nums[i] - nums[j]) >= indexDifference

찾은 인덱스 한 쌍을 반환하는데, 없다면 [-1, -1], 있다면 하나만 반환합니다(i와 j가 같을 수 있음).

<br>

## 풀이
일반적인 이중 순회로 쌍을 찾으면 시간 초과 예상됩니다. 따라서, 큰쪽 인덱스를 기준으로 순회하고, 작은쪽 인덱스에서 최소최대를 갱신하는 방식으로 풀이합니다.
1. indexDifference 간격의 인덱스 left, right 선언 후 right를 끝까지 순회
2. right 순회하면서 left는 항상 최소 간격을 만족하니까, 최소 최댓값 기억하고 인덱스 저장
3. 현재 기억하고 있는 left의 최소 최대가 right 조건 만족하는지 확인하고 정답 반환
    - 해당 쌍이 하나도 없다면 [-1, -1] 반환

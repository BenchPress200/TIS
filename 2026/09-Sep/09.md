# 2026-09-09 TIS
## 타이틀: [Minimum Obstacle Removal to Reach Corner](https://leetcode.com/problems/minimum-obstacle-removal-to-reach-corner/description/)
> 풀이 시간: 30분 

<br>

## 문제 요구 사항
2차원 배열 grid가 주어집니다.
- 가로 세로 m, n
- 1 <= m, n <= 100,000
- 2 <= m * n <= 100,000
- 0: 빈 공간
- 1: 장애물

상하좌우로 이동할 수 있다고 했을 때 (0, 0)에서 출발해서 (m-1, n-1)로 이동하기 위해 제거할 최소 장애물 개수 반환하는 문제입니다.

<br>

## 풀이
1. grid와 똑같은 크기의 배열 선언하고 초기값 할당
2. 해당 배열의 셀은 그 위치에 도달했을 때 최소 장애물 제거 개수 저장
3. 다익스트라로 최소 제거 개수 위주로 탐색
4. 목적지에 도달하면 조기 종료

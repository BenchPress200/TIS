# 2026-09-21 TIS
## 타이틀: [Design Graph With Shortest Path Calculator](https://leetcode.com/problems/design-graph-with-shortest-path-calculator/description/)
> 풀이 시간: 30분 

<br>

## 문제 요구 사항
n개의 노드로 이루어진 가중치가 존재하는 방향 그래프가 주어집니다.
- 1 <= n <= 100
- 노드 번호는 0부터 n-1

간선 정보 edges 배열이 주어집니다.
- 0 <= 길이 <= n * (n-1)
- edges[i]: [from, to, cost]
- 1 <= cost <= 1,000,000 

Graph 클래스 작성하는 문제입니다.
- Graph(int n, int[][] edges): 주어진 n개 노드와 간선 정보로 초기화 
- addEdge(int[] edge): 주어진 edge정보 추가(두 노드 사이에 중복된 간선이 주어지지 않음)
- shortestPath(int node1, int node2): node1과 node2사이의 최소 거리 반환, 경로가 없다면 -1 반환

<br>

## 풀이
1. 이중 리스트로 그래프 정보 저장
2. addEdge로 간선 추가될 때 그래프에 정보 추가
3. shortestPath 호출했을 때 다익스트라 수행
